# Distribution

Developer ID-signed, notarized zip, in-app updates with Sparkle 2, hosted on GitHub (`begemotike/grains`). Same pipeline as Steam Shelf (D19).

## Signing

- `CODE_SIGN_STYLE: Manual`, `DEVELOPMENT_TEAM: 9JHK4XRFW5`, identity `Developer ID Application` in **both** Debug and Release so the app's identity never changes between builds (TCC grants and keychain items follow the identity). Hardened runtime on in Release, `--timestamp` for notarization.
- The embedded `grains-mcp` tool is signed by Xcode as part of the embed phase and re-signed by `release.sh` along with Sparkle's nested helpers (inside out: XPC services, Autoupdate, Updater.app, framework, tool, app).

## Notarization

`xcrun notarytool submit --keychain-profile grains-notary --wait`, gate on `status: Accepted`, then `stapler staple`. One-time: `xcrun notarytool store-credentials grains-notary --apple-id <id> --team-id 9JHK4XRFW5` (an existing `steam-shelf-notary` profile for the same team can be reused by changing `NOTARY_PROFILE`).

## Sparkle

- SwiftPM dependency, `from: 2.10.0`.
- `SUFeedURL` = `https://raw.githubusercontent.com/begemotike/grains/main/appcast.xml`; `SUPublicEDKey` = the public half of a key pair made with Sparkle's `generate_keys` (private key stays in the login keychain; back it up with `generate_keys -x`). Grains uses its **own** key pair, not Steam Shelf's.
- Daily automatic checks plus "Check for Updates…" in the menu bar menu. Not sandboxed, so no XPC exceptions needed.
- `appcast.xml` at the repo root, regenerated by `generate_appcast` from the release zip.

## `scripts/release.sh X.Y.Z [--dry-run]`

1. Validate version, clean tree, no existing tag. 2. Build number = `git rev-list --count HEAD`. 3. `xcodegen generate`, resolve packages (fetches Sparkle tools). 4. `xcodebuild archive` Release. 5. Re-sign nested helpers and the tool with Developer ID. 6. Verify. 7. Zip. 8. Notarize + staple + `spctl` (skipped in dry run). 9. `generate_appcast`. 10. Commit appcast, tag, push, `gh release create` with the zip.

## Versioning

`X.Y.Z` marketing version; build number strictly rising (commit count). Never re-release a version.

## Sparkle key account

The Grains key pair was generated with `generate_keys --account grains` (Sparkle supports one key per keychain account), so it is separate from Steam Shelf's default-account key. `release.sh` must pass `--account grains` to `generate_appcast`. Back it up with `generate_keys --account grains -x grains-sparkle-key.txt` and keep the file offline. Public key: `JRJ5jJC4MgEkyj+CvwIPXDx2uy1EWgsQkDMzZZYiSbM=`.

## Icon

`make icon` renders the app icon procedurally and packs it: `swift scripts/make-icon.swift build/AppIcon.png` draws a 1024×1024 PNG with CoreGraphics (charcoal `#161a20` squircle in the 824 pt macOS tile with a vignette, a low heap of ~60 golden `#e2b714` grains placed by a seeded SplitMix64 so output is deterministic, and a grey `#8a93a3` ascending time-graph line ending in a glowing gold dot; no text so it reads at 16 px). `scripts/make-icns.sh build/AppIcon.png App/Resources/AppIcon.icns` builds the 16–1024 px `.iconset` with `sips` and converts it with `iconutil`. The `.icns` is committed; regenerate only when the artwork changes.
