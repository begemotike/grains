# Roadmap

## v1 (ships)

Global shortcut, optional corner summon, single-line text-first overlay, control/typing modes, one running timer with crash recovery, SQLite persistence, weekly two-lane graph with live stats, week navigation, minimal History editing, weekly CSV exports, read-only stdio MCP server, menu bar item, Settings (shortcut, corner, export folder, week start, target hours, launch at login, share notes with AI), Sparkle updates.

## Deferred

- Approval-gated MCP edit tools (rename client, merge labels, fix times) with an audit table; raw text never changes.
- Streamable HTTP transport + tunnel recipe for ChatGPT connectors.
- Client directory with aliases and normalized `client_id`.
- Light theme; bundled Roboto Mono option.
- Daily bars for the last seven days; stacked time by client; session timeline; past-week comparison.
- Billing rates, invoicing, cloud sync, project hierarchy: out of scope by design.
